# 2차 발표 영상 대본 (1분 30초)

영상(`2차발표_영상.mp4`, 소리 없음)을 틀어 놓고 시간에 맞춰 읽으면 돼요. 한 줄이 그 구간 길이에 맞게 쓰여 있어요(1초에 4~5글자 정도의 보통 속도).

| 시간 | 화면 | 읽을 말 |
|---|---|---|
| 0:00 – 0:04 | 표지 | 데스크테리어 의뢰소 2차 진행 발표, 한준상입니다. |
| 0:04 – 0:07 | 목차 | 게임 설명, 진행 상황, 변경점, 데모 순서입니다. |
| 0:07 – 0:17 | 게임 설명 | 손님의 애매한 주문을 듣고, 물건을 사서 책상을 꾸미고 PC를 조립해 납품하는 가게 운영 게임입니다. |
| 0:17 – 0:29 | 계획 대비 진행 | 4주 계획 중 배치, PC 조립, 의뢰와 채점은 모두 완료했고, 마무리인 밸런스를 진행 중입니다. 의뢰와 소품 수는 계획의 두 배를 넘었습니다. |
| 0:29 – 0:37 | 기획 변경 | 스테이지 방식에서, 하루 영업을 하며 가게가 성장하는 운영 게임으로 바꿨습니다. |
| 0:37 – 0:43 | ① 손님 주문 | 손님은 원하는 걸 돌려 말해서, 대사 속 힌트를 읽어야 합니다. |
| 0:43 – 0:51 | ② 쇼핑 | 주문을 듣고 필요한 소품과 부품만 삽니다. 아낀 예산은 가게 마진이 됩니다. |
| 0:51 – 1:00 | ③ 책상 꾸미기 | 책상은 자유롭게 배치하고 색도 바꿀 수 있습니다. 스탠드 옆에 책을 두면 독서 콤보가 됩니다. |
| 1:00 – 1:10 | ④ PC 조립 | PC는 실제 순서대로 조립합니다. 소켓 레버를 열어야 CPU가 들어가고, 구리스를 바르고 쿨러를 답니다. |
| 1:10 – 1:18 | ⑤ 부팅 · 배선 | 전원을 켜면 바이오스가 뜨고, 모니터를 DP 포트에 연결합니다. |
| 1:18 – 1:24 | ⑥ 납품 | 납품하면 별점과 함께, 손님이 숨겨 둔 조건이 공개됩니다. |
| 1:24 – 1:30 | 다음 계획 | 다음에는 밸런스와 의뢰 기준을 다듬겠습니다. 감사합니다. |

- 유튜브에 올린 뒤 **직접 재생해서 소리 · 화질 확인** (설정 → 화질 720p 이상)
